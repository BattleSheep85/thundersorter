# Thundersorter has moved

This project now lives on GitLab:

**https://gitlab.com/chrisputer/thundersorter**

All future development, issues, and releases happen there. This GitHub
repository is archived and read-only.

Latest release: https://gitlab.com/chrisputer/thundersorter/-/releases

**Direct download:** [thundersorter.xpi](https://gitlab.com/chrisputer/thundersorter/-/releases/permalink/latest/downloads/thundersorter.xpi) (always the latest release)

## If you already have the add-on installed

You do not need to do anything. Thunderbird's built-in add-on update system
will detect the new release on GitLab and update Thundersorter automatically,
the next time it checks for updates.
